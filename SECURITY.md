# Sécurité

## Signaler un problème

Évitez de publier publiquement une vulnérabilité exploitable ou des renseignements personnels dans une issue. Utilisez plutôt la fonction **Report a vulnerability** de GitHub si elle est activée pour ce dépôt.

## Modèle de sécurité actuel

MiniTransfert Portable est destiné au partage temporaire entre personnes de confiance. Les échanges sont directs et utilisent HTTP; ils ne sont donc pas chiffrés par TLS. Le nom DDNS facilite l’accès, mais ne masque pas l’adresse IP publique.
